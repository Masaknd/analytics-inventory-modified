連携は任意です

このツールは連携なしでも通常どおり動きます。設定するのは 相手ツール（改善コックピット / UX-Testing-Tools）への行き先だけで、 計測データの収集・品質チェック・通知の挙動は変わりません。 連携を外したいときは URL を空にして保存してください。

① 管理システム側で設定すること

改善コックピットのURL（ブラウザで開くときのアドレス）を入れてください。ローカルで動かしているなら http://127.0.0.1:3000 のような形です。

{% if from_env %}

環境変数 COCKPIT_URL が設定されているため、そちらが優先されます（画面からは変更できません）。

{% endif %} {% if cockpit_url %}

設定済み: {{ cockpit_url }} — プロパティ詳細に「このサイトの改善を見る」の行き先が出ます。

{% endif %}

② 改善コックピット側で設定すること

改善コックピットの「データ連携」ページに、この管理システムのURLを登録してください。 相手側はそのURLの /api/health で接続を確認し、 /api/property/<プロパティID>/summary で計測品質を読み取ります（読み取り専用・認証なし）。

別のPCから繋ぐ場合は 127.0.0.1 ではなくこのPCのIPアドレスやホスト名に読み替えてください。 社外には公開せず、同じネットワーク内に留めることを前提にしています。

連携すると何が変わるか

渡す内容相手側での使われ方
ヘルスグレード・スコア・品質チェックの件数と上位の指摘改善プロジェクトの Measure 段に「計測はそもそも信用できるか」を表示
キーイベントの定義数と実測（0件かどうか）「CVが1件も計測されていない」警告の根拠。未確認のときは警告しない
監視除外・一時停止の状態ここで監視対象外にしたプロパティを、相手側が品質警告として出さない
ホスト名棚卸しの上位診断しようとしているURLが計測対象ホストかの照合（ステージングを本番と誤認しない）
直近の変化イベント件数と最新日前後比較の区間に計測設定の変更が挟まっていないかの確認

渡すのは計測設定とその品質の要約だけです。アクセス権限の一覧・認証情報・AI分析の本文は渡しません。
